# 🌐 Portal de Simuladores Operacionais

Este projeto é um site centralizador para acesso rápido aos simuladores de logística e empacotamento desenvolvidos por Ânderson Oliveira, hospedados em Streamlit e integrados via Vercel.

## 📦 Simuladores Disponíveis

✅ **Simulador de Caixas 2D**  
Monte caixas de forma otimizada em duas dimensões.  
🔗 [Acessar Simulador 2D](https://simuladorcaixas2d.streamlit.app/)

✅ **Simulador de Caixas 3D**  
Empacotamento tridimensional inteligente para otimizar espaço e reduzir custos.  
🔗 [Acessar Simulador 3D](https://simuladorcaixas3d.streamlit.app/)

✅ **Simulador de Separação de Produtos**  
Simule tempo de separação, gargalos e eficiência de esteiras ou processos logísticos.  
🔗 [Acessar Simulador de Separação](https://simuladorparting-line.streamlit.app/)

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 com responsividade e animações
- JavaScript Vanilla
- Google Fonts (Poppins)
- Ícones personalizados e vetores
- Integração com apps Streamlit
- Hospedagem no [Vercel](https://vercel.com)
